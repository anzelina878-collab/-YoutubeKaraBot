# YoutubeKaraBot

Личный бот: карточки идей длинных YouTube-видео на русском языке, с подтверждающими примерами и ссылками.

Каждая карточка содержит 3 редакционные идеи, подачу, сложность и примеры как минимум двух независимых каналов. Идеи — подготовленные шаблоны для четырёх направлений (мегастройки, исторический быт, география, исчезнувшие бренды); это не семантический анализ просмотренных видео и не полный охват всех ниш.

Фильтры: публикация до 30 суток назад, длина от 8 минут, без трансляций; канал 100–300000 подписчиков (MAX_SUBSCRIBERS), просмотры минимум MIN_VIEWS (по умолчанию 10000), минимум вдвое больше подписчиков и минимум вдвое выше медианы среднего темпа соседних роликов. Последнее сравнение приблизительное: возраст роликов различается. Язык запроса не гарантирует язык видео. Содержание видео не просматривается.

Расписание Europe/Kyiv: 10,12,14,16,18,20. Одна карточка направления в день, максимум четыре за день. Без достаточных примеров сообщений нет. История SQLite сохраняется на volume. При аварии между отправкой и записью возможен повтор.

Python 3.11+, сторонние библиотеки не нужны. Настройки: TELEGRAM_BOT_TOKEN, TELEGRAM_CHAT_ID, YOUTUBE_API_KEY, DATABASE_PATH. Секреты только в .env или переменных хостинга. Railway: см. RAILWAY.md. Настройка chat_id: python bot.py --setup после Start своему боту. Предпросмотр: python bot.py --dry-run; реальная отправка: python bot.py --once; постоянный запуск: python -u bot.py. Проверки: python -m unittest -v.

До 48 поисковых запросов в день (4800 единиц квоты YouTube), плюс метаданные и сравнения; повторы увеличивают расход. Ключ OpenAI не нужен. Четыре локальных теста прошли; новая версия живыми ключами не проверена.
